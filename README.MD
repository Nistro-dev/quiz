# Quiz app

## 1. Comment définiriez-vous le Devops ?
Le DevOps c'est une façon de travailler qui permet aux développeurs de plus communiquer avec les personnes non techniques afin de mieux collaborer. Il me semble que c'est une philosophie.

## 2. Qu’impose le Devops ?
- Travailler en équipe....
- Tests unitaires
- CI/CD

## 3. Quels sont les inconvénients ou les faiblesses du Devops ?
- Un peu complex et long à mettre en place.
- Travailler en équipe...

## 4. Quel est votre avis sur le Devops ?
- Je trouve que cela oblige à fiare les choses bien, le déploiement continue c'est super, cela permet au client d'avoir un aperçu tout au long du projet. Même si je préfère travailler en solo, c'est toujours intéressant de travailler à plusieurs.

## 5. Quels sont les tests primordiaux pour toute application ?
- Unitaires
- Intégration
- Fonctionnel
